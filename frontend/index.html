ℹ️ О сервисе

Веб-приложение для просмотра расписания пригородных электропоездов. Данные предоставляются через API Яндекс.Расписаний.

  • ✅ Поиск по названию станции
  • ✅ Поиск по карте (координатам)
  • ✅ Расписание между станциями
  • ✅ Избранные остановки
  • ✅ Адаптация под мобильные устройства

Примечание: Проект выполнен в учебных целях для курса «Безопасность веб-приложений».
