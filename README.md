# Безопасность веб-приложений. Лабораторка №2

## Описание проекта

Веб-приложение для поиска и просмотра расписания пригородных поездов (электричек) по станциям России. Использует API Яндекс.Расписаний для получения актуальных данных о движении поездов.

## Функциональные возможности

### Поиск по станции

* Автодополнение при вводе названия станции
* Просмотр расписания отправления/прибытия
* Добавление станций в избранное

### Поиск по маршруту

* Поиск электричек между двумя станциями
* Отображение времени отправления и прибытия

### Карта станций

* Отображение ближайших станций на карте при выборе области и нажатии на кнопку
* Выбор станции для просмотра расписания, ее добавление в избранное
* Отображение расположения станции при ее выборе через Поиск

### Избранное
* Сохранение избранных станций в localStorage
* Быстрый доступ к часто используемым станциям

### Кэширование

* Все станции загружаются от Яндекса один раз за сессию сервера
* Срок жизни кэша: 24 часа
* При повторных запросах данные отдаются из памяти
* Загруженные станции сохраняются в localStorage
* Срок жизни кэша: 24 часа
* После перезагрузки страницы поиск работает мгновенно


## Технический стек

### Frontend

* React 18.x (UI-библиотека)
* Vite 5.x (сборщик проекта)
* Zustand 4.x (управление состоянием)
* OpenLayers 8.x (интерактивная карта)
* Axios 1.x (HTTP-запросы)
* CSS3 (кастомные свойства, адаптивный дизайн)

### Backend

* Node.js
* Express.js
* API Яндекс.Расписаний (v3.0)
* node-fetch 2.x
* CORS
* dotenv

## Требования
* Node.js 16+
* npm




Реализовано веб-приложение для поиска расписания электричек с клиент-серверной архитектурой. Бэкенд на Node.js делает запросы к API Яндекс.Расписаний с кэшированием данных, фронтенд на HTML/CSS/jQuery обеспечивает поиск станций с автодополнением, просмотр расписания отправления/прибытия, маршруты между станциями и интерактивную карту. Предусмотрена адаптивная вёрстка для мобильных устройств, сохранение избранного в localStorage и динамическая подгрузка контента без перезагрузки страницы. Также проведена работа с DOM/CSSOM и интеграции с открытым API.
